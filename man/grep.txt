grep(1) — search lines containing a text pattern

SYNOPSIS
    grep [options] <file...>

DESCRIPTION
    Search lines containing a text pattern. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
