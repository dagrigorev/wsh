sleep(1) — pause execution for seconds

SYNOPSIS
    sleep [options] [arguments...]

DESCRIPTION
    Pause execution for seconds. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
