NAME
    wsh - Windows-first shell and terminal environment.

SYNOPSIS
    Wsh.exe
    help
    man <topic>

DESCRIPTION
    Wsh combines a native Windows terminal emulator with an integrated shell
    runtime. The built-in shell is selected by setting general.shell = "wsh" in
    %APPDATA%\Wsh\Wsh.toml. External shells may be launched through ConPTY by
    changing general.shell to cmd.exe, powershell.exe, pwsh.exe or another path.

CONFIGURATION
    Main config: %APPDATA%\Wsh\Wsh.toml

    [general]
    shell = "wsh"
    theme = "catppuccin-mocha"
    title = "Wsh - ${cwd}"

    Title placeholders:
      ${cwd}      current working directory
      ${theme}    configured theme name
      ${version}  Wsh version

THEMES
    Built-in themes are stored in dist\themes and copied by wshinit:
      catppuccin-mocha, nord, solarized-dark, material-ocean, wsh-light

    To switch theme, edit Wsh.toml:
      [general]
      theme = "nord"

SEE ALSO
    man ls, man md, man tree, man wshinit

LOGGING
    Runtime logs are written to:

        %LOCALAPPDATA%\Wsh\logs\wsh.log

    Fallback location when LOCALAPPDATA is unavailable:

        <wsh-exe-directory>\logs\wsh.log

    The active log is limited to 10 MiB. When the next record would exceed
    this limit, Wsh clears the file and continues writing from the beginning.

    The log captures startup/shutdown, Win32 failures, PTY errors, renderer
    initialization problems, invalid CRT parameters, signals, unhandled C++
    exceptions and structured exceptions.
