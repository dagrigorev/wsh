sort(1) — sort input lines from files

SYNOPSIS
    sort [options] <file...>

DESCRIPTION
    Sort input lines from files. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
