dirname(1) — print directory portion of a path

SYNOPSIS
    dirname [options] [arguments...]

DESCRIPTION
    Print directory portion of a path. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
