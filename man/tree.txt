NAME
    tree - print a directory tree.

SYNOPSIS
    tree [options] [path]

OPTIONS
    -a, --all      include hidden files.
    -d, --dirs     show directories only.
    -L <n>         limit traversal depth.
    -h, --help     print command help.

EXAMPLES
    tree
    tree -L 3 src
    tree -d C:\work
