NAME
    ai - built-in AI assistant with proactive reasoning and command
    commentary

SYNOPSIS
    ai status
    ai suggest [build|test|git]
    ai explain
    ai fix
    ai on
    ai off
    ai commentary [on|off|test <cmd...>]
    ai phi4 [status|reload]

DESCRIPTION
    Wsh includes a local AI assistant that helps you work more efficiently
    in the terminal. All AI processing runs entirely on your machine with
    no network access.

    Proactive reasoning (enabled by default):
      As you type, Wsh detects typos, suggests completions, and provides
      friendly hints. Suggestions appear as an overlay below the current
      line. The assistant recognises common tools: git, npm, cmake, docker,
      dotnet, python, and many more.

    Command commentary (new in v1.0):
      After you press Enter, Wsh can generate a short playful one-line
      reaction to your command. This uses a local Phi-4 model when
      available, or deterministic fallback phrases.

SUBCOMMANDS
    ai status
        Show current AI state, loaded provider info, commentary status,
        and Phi-4 model status.

    ai suggest
        Show project-aware suggestions based on detected project files
        (CMakeLists.txt, *.sln, *.csproj, package.json, .git/).

    ai suggest build
        Filter suggestions to build-related commands.

    ai suggest test
        Filter suggestions to test-related commands.

    ai suggest git
        Filter suggestions to Git-related commands.

    ai explain
        Analyse the last command and explain its exit code or error.

    ai fix
        Suggest a correction for a mistyped command.

    ai on
        Enable proactive AI assistance (default).

    ai off
        Disable proactive AI assistance (also disables commentary).

    ai commentary on
        Enable command commentary.

    ai commentary off
        Disable command commentary.

    ai commentary test <command...>
        Generate commentary for the given command and print it.

    ai phi4 status
        Show Phi-4 model status (loaded or missing) and path.

    ai phi4 reload
        Reload the Phi-4 runtime.

EXAMPLES
    ai status
    ai suggest
    ai suggest git
    ai explain
    ai fix
    ai commentary on
    ai commentary test tree ?
    ai phi4 status

FILES
    The n-gram language model is embedded in the binary. No external model
    files are required for basic suggestions.

    For commentary, a Phi-4 GGUF model may be placed at:
        models/phi-4/model.gguf

    Model path resolution order:
        1. Config: ai.phi4.model_path in Wsh.toml
        2. Environment variable: WSH_PHI4_MODEL_PATH
        3. Relative to binary: ./models/phi-4/model.gguf
        4. Relative to binary: ../models/phi-4/model.gguf
