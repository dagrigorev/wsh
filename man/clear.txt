clear(1) — clear the terminal screen

SYNOPSIS
    clear

DESCRIPTION
    Clear the terminal screen. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
