uniq(1) — collapse adjacent duplicate lines

SYNOPSIS
    uniq [options] <file...>

DESCRIPTION
    Collapse adjacent duplicate lines. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
