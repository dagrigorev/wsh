basename(1) — strip directory and extension context from a path

SYNOPSIS
    basename [options] [arguments...]

DESCRIPTION
    Strip directory and extension context from a path. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
