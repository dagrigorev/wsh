uname(1) — print system name

SYNOPSIS
    uname

DESCRIPTION
    Print system name. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
