cat(1) — concatenate files and print them to stdout

SYNOPSIS
    cat [options] <file...>

DESCRIPTION
    Concatenate files and print them to stdout. This is a Wsh companion utility intended to provide
    a familiar Linux-like console environment on Windows. The implementation is
    intentionally lightweight and Windows-native; it is not a full GNU coreutils
    clone yet.

OPTIONS
    -h, --help, /?
        Show command help.
