NAME
    htop - show Windows process and resource usage.

SYNOPSIS
    htop [options]

DESCRIPTION
    Show a real snapshot of system CPU, memory and process usage using Win32
    telemetry. Process CPU percentages are measured across a short sampling
    interval, not guessed. Processes that cannot be queried are still listed
    with the data Windows exposes through the process snapshot.

OPTIONS
    -n <count>      show at most count processes. Default is 25.
    -d <ms>         sampling delay in milliseconds. Default is 700.
    -s <key>        sort by cpu, mem, pid, or name. Default is cpu.
    -w, --watch     refresh until interrupted.
    --color=WHEN    color output: auto, always, never.
    -h, --help      print command help.

EXAMPLES
    htop
    htop -n 40 -s mem
    htop -w -d 1000
