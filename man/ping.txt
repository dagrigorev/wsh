NAME
    ping - send ICMP echo probes.

SYNOPSIS
    ping [options] host

DESCRIPTION
    Send real Windows ICMP echo requests and print per-reply latency, TTL,
    timeout information, packet-loss summary and min/avg/max round-trip times.

OPTIONS
    -c, -n <count>    number of probes. Default is 4.
    -t, --continuous  ping until interrupted.
    -w <ms>           reply timeout in milliseconds.
    -i <ms>           interval between probes in milliseconds.
    -s <bytes>        payload size, clamped to 1..1400 bytes.
    --color=WHEN      color output: auto, always, never.
    -h, --help        print command help.

EXAMPLES
    ping 127.0.0.1
    ping -n 10 -w 500 github.com
    ping -t 1.1.1.1
