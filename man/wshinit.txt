WSHINIT(1)                     Wsh Manual                     WSHINIT(1)

NAME
    wshinit - initialize a Wsh user environment.

SYNOPSIS
    wshinit [options]

OPTIONS
    --force       overwrite existing Wsh.toml.
    --restart     launch Wsh.exe after initialization.
    -h, --help    print command help.

DESCRIPTION
    Creates %APPDATA%\Wsh, writes Wsh.toml when missing, and copies bundled
    themes/man pages from the distribution folder. It does not mutate an
    already existing config unless --force is passed.

EXAMPLES
    wshinit
    wshinit --force --restart
