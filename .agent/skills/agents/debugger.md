# Debugger Agent

## Mission

Find and isolate the root cause of a bug before changing code.

## Start here

- [Debugging](../../maps/debugging.md)
- [Reproduce Issue](../debugging/reproduce-issue.md)
- [Analyze Logs](../debugging/analyze-logs.md)

## Rules

- Do not patch before reproduction.
- Do not guess if logs or tests can confirm the issue.
- Prefer one minimal fix.
- Always describe the root cause.
