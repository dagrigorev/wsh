# Inspect Task

## Purpose

Clarify the task, constraints, output, and verification before changing files.

## When to use

Use at the beginning of any non-trivial task.

## Inputs

User request; existing context; known constraints

## Read first

- [Task_Template](../../TASK_TEMPLATE.md)
- [Router](../../ROUTER.md)
- [Context_Policy](../../CONTEXT_POLICY.md)

## Steps

1. Extract goal.
2. list constraints.
3. identify unknowns.
4. choose map.
5. choose first skill.
6. define verification.

## Output

Filled task summary or short plan.

## Verification

The next skill and verification path are clear.
