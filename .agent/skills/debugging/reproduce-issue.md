# Reproduce Issue

## Purpose

Create a reliable reproduction before changing code.

## When to use

Use at the start of runtime bug work.

## Inputs

Task; relevant files; constraints

## Read first

- [Context_Policy](../../CONTEXT_POLICY.md)
- [Project Summary](../../memory/project-summary.md)
- [Commands](../../memory/commands.md)

## Steps

1. Read minimal context.
2. inspect relevant files.
3. make a small plan.
4. apply focused work.
5. verify.
6. document result.

## Output

Reproduce Issue result with short explanation and links.

## Verification

Run the nearest relevant build, test, or manual check.

## Anti-patterns

- Do not make unrelated changes
- Do not invent project facts
- Do not skip verification.
