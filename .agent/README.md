# Local Agent System

This directory is a lightweight navigation system for local multi-agent work in Open Code with Ollama models.

It is designed as a mind map: agents should follow links to the smallest relevant document instead of loading the whole repository or all instructions at once.

## Start here

1. Read [Context Policy](CONTEXT_POLICY.md)
2. Read [Router](ROUTER.md)
3. Select a map from [Mind Maps](maps/index.md)
4. Select a skill from [Skills Index](skills/index.md)
5. Use [Task Template](TASK_TEMPLATE.md)
6. Finish with [Handoff Template](HANDOFF_TEMPLATE.md)

## How to work

- Start from the task, not from the full repository.
- Use [Router](ROUTER.md) to choose the shortest path.
- Use one map and one skill at a time.
- Read [Memory](memory/project-summary.md) before scanning large folders.
- Verify with commands from [Commands](memory/commands.md).
- Record decisions in [Known Decisions](memory/known-decisions.md) when they affect future work.
