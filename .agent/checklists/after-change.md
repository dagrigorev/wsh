# After Change Checklist

- [ ] Change is minimal.
- [ ] No unrelated files were modified.
- [ ] Active modular source files were changed, not legacy duplicates by accident.
- [ ] Build command was run or reason was documented.
- [ ] Tests were run or reason was documented.
- [ ] Manual QA was done for UI/input/ConPTY/rendering changes or reason was documented.
- [ ] Docs/man pages were updated if user-facing behavior changed.
- [ ] Result was summarized.
- [ ] Handoff was written if needed.
