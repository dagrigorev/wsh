# Bugfix Done Checklist

- [ ] Issue was reproduced or non-reproduction was documented.
- [ ] Root cause was identified.
- [ ] Fix is minimal.
- [ ] Original failing case passes.
- [ ] Nearest automated tests pass or skipped reason is documented.
- [ ] Manual QA is recorded for UI/input/ConPTY/rendering bugs.
- [ ] Logs were checked for runtime crashes.
- [ ] Handoff explains cause, fix, and verification.
